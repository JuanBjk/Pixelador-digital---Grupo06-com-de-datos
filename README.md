## Ejecutar Localmente

**Requisitos previos:** Node.js

1. Instalar las dependencias:
   npm install
2. (Opcional) Configurar variables de entorno en `.env.local` si tu despliegue lo requiere.

3. Ejecutar la aplicación:
   npm run dev
 
 Ejemplos incluidos
 
 - Hay tres imágenes de ejemplo en `assets/examples/` que pueden seleccionarse desde la UI como presets:
   - `manzanas_y_banana.jpeg` — Par de frutas
   - `gata_perlita.jpeg` — Gatita
   - `laluna.jpeg` — Foto de la luna

 Selección de presets

 - En la sección de selección de imagen (panel izquierdo) puedes elegir cualquiera de las tres imágenes de ejemplo o arrastrar tu propia imagen.

 Notas

 - El procesamiento de las imágenes ocurre en el navegador; no se requiere clave externa.
 - Si necesitas que añada o reemplace las imágenes de ejemplo, dime cuáles quieres usar.
